# BrisaPlan

Aplicación web progresiva (PWA) minimalista para organizar agenda, tareas con color personalizable, hábitos con rachas, Pomodoro y bandeja de correos.

## Estructura de carpetas
- `index.html` — Aplicación principal con verificación de correo, modo oscuro suave y 5 secciones (`Hoy`, `Agenda`, `Tareas y Hábitos`, `Correos`, `Mi Espacio`).
- `manifest.json` — Manifiesto PWA instalable.
- `css/` — `variables.css`, `layout.css`, `components.css`.
- `js/` — `config.js`, `storage.js`, `tasks-habits.js`, `agenda.js`, `mail-classroom.js`, `legal.js`, `app.js`.
- `widgets/desktop-wallpaper.html` — Widgets cristal independientes para escritorio.

## Publicación en GitHub Pages
1. Descomprime `BrisaPlan.zip` y sube el contenido a la raíz de tu repositorio en GitHub.
2. En **Settings → Pages**, selecciona la rama `main` y carpeta `/ (root)`, y guarda.
